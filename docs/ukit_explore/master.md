# About uKit Explore

Basically, uKit Explore is a board that is Arduino based designed for competition usage. It is carefully designed for beginner to be used as the controller for competition, it will help you to explore the wonderful electronics world and how fun the technology is.

In uKit Explore parts, it is divided into two category which are the electronics and building blocks. For electronics, it includes the Explore main controller board, motors and sensors. While for building blocks, it consists of the decoration parts as well as different type of connectors.
