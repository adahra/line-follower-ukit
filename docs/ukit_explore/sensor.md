# Sensor

- [setEyelightAllPetals(id,red,green,blue)](seteyelightallpetals.md): Control all the 8 petals (pixels) of the eye lamp to light up a set of color.
- [setEyelightPetals(id,petalsnum,petals)](seteyelightpetals.md): Customize eye lamps, 8 petals (pixels) light up in different colors.
- [setEyelightLook(id,face,times,red,green,blue)](seteyelightlook.md): Set the emoticons to light up different color of expressions (non-blocking)
- [setEyelightLookUntil(id,face,times,red,green,blue)](seteyelightlookuntil.md): 设置眼灯亮不同颜色的表情（阻塞）
- [setEyelightScene(id,scene,times);](seteyelightscene.md): Set the eye lamp to the different scene mode (non-blocking)
- [setEyelightSceneUntil(id,scene,times)](seteyelightsceneuntil.md): Set the eye lamp to the different scene mode (blocking).
- [setEyelightOff(id)](seteyelightoff.md): Turn off the eye lamp
- [setUltrasonicRgbled(id,red,green,blue)](setultrasonicrgbled.md): Control the ultrasonic sensor’s LED to light up and set the color
- [setUltrasonicRgbledOff(id)](setultrasonicrgbledoff.md): Turn off the ultrasonic sensor’s LED light.
- [readUltrasonicDistance(id)](readultrasonicdistance.md): Reading ultrasonic sensor distance
- [readInfraredDistance(id)](readinfrareddistance.md): Get infrared sensor distance value.
- [readButtonValue(id)](readbuttonvalue.md): Get the state of the touch sensor
- [readLightValue(id)](readlightvalue.md): Get the light value from the light sensor.
- [readSoundValue(id)](readsoundvalue.md): Get the sound intensity.
- [readHumitureValue(id,choice)](readhumiturevalue.md): Get the temperature or humidity value
- [readColorRgb(id)](readcolorrgb.md): Get the RGB value of color sensor.
- [readColor(id,color)](readcolor.md): Recognize the specific color from the color sensor
